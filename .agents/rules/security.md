# Security

Prefix: SEC. People run these defaults in production without reading them, so the defaults have to be the safe choice.

- **SEC1:** Secure by default, permissive on request. CORS allows no origin unless configured (`GetDefaultCORSAllowAllOrigins`), the WebSocket upgrader checks `Origin` against `Host` (`GetDefaultWebSocketCheckOrigin`), and both open up only through `aichteeteapee.FuckSecurity()` or an explicit option. A new permissive behaviour follows the same pattern: off by default, readable through the dev-mode flag in `defaults.go` or an option.
- **SEC2:** Static serving rejects `..` in the cleaned path and then checks that the symlink-resolved file stays under the symlink-resolved directory (`validateAndBuildPath` in `serbewr/server.go`). Both checks stay. Directory listings are off unless `DirectoryIndexingType` says otherwise.
- **SEC3:** Uploads keep `filepath.Base` on the client file name, `O_CREATE|O_EXCL` with mode `0600`, a `0750` upload directory, and the `http.MaxBytesReader` total size limit (`DefaultFileUploadMaxSize`, 100MB) in `serbewr/handlers.go`.
- **SEC4:** RequestID accepts a client `X-Request-ID` only when it is at most 128 characters of `[A-Za-z0-9._-]`, and replaces anything else with a fresh UUID (`serbewr/middleware/request_id.go`). Values from headers never reach a log or a response unvalidated.
- **SEC5:** BasicAuth and BearerAuth compare in constant time by default, hashing both sides with SHA-256 first so the comparison length does not leak. Empty bearer tokens are dropped, so an unset env var never authenticates.
- **SEC6:** `prawxxey.ForwardRequest` and `klhayyent.New` treat the upstream or base URL as trusted configuration. They accept only absolute `http` or `https` URLs with a host and no user info. `klhayyent` also rejects absolute, scheme-relative, encoded-traversal and control-character targets, and follows redirects only on the base URL's scheme and host for at most 10 hops. Neither package does SSRF filtering; the docs say so and callers must do it. Do not loosen any of these checks.
- **SEC7:** The proxy cache never stores a response for a request with `Authorization`, `Cookie` or a no-cache directive, never when the client has a cookie jar, and never a response with `Set-Cookie`, `Vary` or a `private`, `no-cache` or `no-store` directive. Response bodies are capped (100MB proxy default, 10 MiB client default).
- **SEC8:** `wsunixbridge` creates its socket directory `0700` and each socket `0600`.
- **SEC9:** The dev image pins its base by digest, its Alpine packages by version, gitleaks by SHA-256 and Semgrep by hash (`Dockerfile.dev`, `requirements-semgrep.txt`). `make sec` gates on gitleaks (tree and history), govulncheck and Semgrep. Do not unpin or relax them. A false positive gets a narrow, commented allowlist entry (`.gitleaks.toml`, a `// nosemgrep` with its reason), never a broad one.
